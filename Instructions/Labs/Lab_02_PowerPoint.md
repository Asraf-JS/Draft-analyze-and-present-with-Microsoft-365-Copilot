# Lab 02 — Build a client presentation from scratch

## Scenario

You are a **Wealth Management Advisor** at Mayfield Bank Berhad. Your manager has asked you to prepare a short presentation for a group of high-net-worth clients about the bank's **Structured Investment Products** for Q1 2025. You have a Word document with key product details. You will use Copilot in PowerPoint to turn it into a polished deck.

In this lab, you learn how to:

- Create a presentation from a Word document using Copilot.
- Add and rewrite slides using natural language.
- Adjust tone, length, and design using prompts.

**This lab should take approximately 30 minutes.**

---

## Task 1: Create a presentation from a Word document

1. Open the file **Lab_02_Product_Brief.docx** from your OneDrive > Documents folder.

    > ***Note:** This document contains a brief on Mayfield Bank's Q1 2025 Structured Investment Products. Review it quickly before proceeding.*

1. Open **PowerPoint** and create a new blank presentation.

1. Select the **Copilot** button on the **Home** ribbon.

1. In the Copilot panel, type:

    ```
    Create a presentation based on the file Lab_02_Product_Brief.docx
    ```

1. Wait for Copilot to generate the slides. It will produce a deck based on the content of your Word document.

    > ***Note:** Copilot needs the file to be saved in OneDrive or SharePoint to reference it. If the file is on your local desktop, move it to OneDrive first.*

---

## Task 2: Refine the slides

1. Review the generated slides. You may find some are too text-heavy or missing a slide you need.

1. In the Copilot panel, type:

    ```
    Add a slide after slide 2 with the title "Why Invest Now?" that highlights 3 reasons why Q1 2025 is a good time for structured products in Malaysia.
    ```

1. Then try:

    ```
    Make the tone on all slides more professional and concise. Remove any bullet points with more than 10 words.
    ```

---

## Task 3: Adjust the design

1. In the Copilot panel, type:

    ```
    Change the theme to something that looks clean and corporate — suitable for a Malaysian bank presentation.
    ```

1. Then type:

    ```
    Add speaker notes to each slide with one key talking point the presenter should emphasise.
    ```

1. Review the speaker notes by switching to **View > Notes Page**.

---

## Task 4: Add a closing slide

1. In the Copilot panel, type:

    ```
    Add a closing slide that thanks the audience and includes a call to action — invite clients to book a one-on-one consultation with their Wealth Advisor at Mayfield Bank.
    ```

1. Review the slide and adjust the wording if needed by typing a follow-up prompt directly in the panel.

---

## Lab complete

You have created a client-ready presentation from a Word document, refined the content and tone, and added speaker notes — all using natural language prompts in Copilot.
